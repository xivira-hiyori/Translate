# Penerjemah Novel

Penerjemah Light Novel dan Web Novel (Inggris/Jepang/Mandarin) ke Bahasa Indonesia dengan Gemini.

Variabel lingkungan: `GEMINI_API_KEY`, `APP_PASSWORD` (opsional), `REQUEST_PAUSE` (opsional, default 6 detik).
